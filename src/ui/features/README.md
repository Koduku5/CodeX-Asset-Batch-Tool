# 前端功能域

根 `App.tsx` 只挂载正式工作台。业务状态、控制器和视图已经按领域拆分：

- `workbench/`：应用组合层，以及项目、任务、Codex、阶段耗时控制器；监听页各区块是独立组件。
- `prompt-studio/`：批次配置、模板、字段编辑、路由分支、预设交换、条件判断和抽屉舞台。
- `pending-assets/`：待确认资产的分页模型、记录编辑器和确认对话框。

边界约束：

1. 组件不得直接拼 API 地址或调用原生命令；统一调用 `src/ui/services/` 适配器。
2. 领域状态与副作用放在对应 hook/controller，展示组件只接收经过校验的数据和回调。
3. 跨领域视觉原语放在 `src/ui/components/ui/`；业务组件不得反向依赖应用入口。
4. Prompt Studio 保持动态导入，未打开时不加载编辑器和预设交换工作台。
5. 新功能进入现有领域或建立新领域，不在 `App.tsx`、服务聚合器或单个页面中继续堆叠职责。

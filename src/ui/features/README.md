# 前端功能域

`App.tsx` 目前保留已经验证过的桌面交互。后续新增功能或调整布局时，按功能域逐步迁入本目录，不再继续扩大根组件。

- `shell/`：单窗口舞台、主题、悬浮导航、面板切换和键盘操作。
- `projects/`：项目卡片、新建、重命名、删除和项目切换。
- `monitor/`：当前任务、总进度、阶段卡片、耗时、资产拆分概览和剧本入口。
- `batch/`：批量出图设置、参考图、后端选择、队列和单项出图测试。
- `prompt-studio/`：提示词模板、路由分支、预设同步、Agent 判断与校验。

约束：

1. `App.tsx` 最终只负责组合功能区和保存全局导航状态。
2. 功能组件不得直接拼 API 地址或调用原生命令；统一调用 `src/ui/services/`。
3. 跨功能共享的视觉原语放在 `src/ui/components/ui/`，业务组件留在各自功能域。
4. 大型面板使用动态导入；Prompt Studio 未打开时不加载其编辑器和预设工作台。
5. 每迁出一个功能域，先保持现有 DOM 契约与测试通过，再单独进行布局优化。

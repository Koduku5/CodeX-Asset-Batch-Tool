## 目标

把世界观写成支撑剧情成立、并能持续约束视觉生产的“运行规则”，而不是题材标签、剧情梗概或形容词堆砌。最终读者应能回答：这个世界靠什么机制运转，规则在什么条件下成立，组织、资源、能力与生活为何形成当前状态。

## 单集提炼

### 1. 先做内部证据判断

逐段扫描本集，把候选信息先在推理中核对四件事，不把这张内部判断表写入 Cache：

1. 原文是否直接陈述，或是否由多处明确线索唯一导出。
2. 它是否跨场景持续成立，或具有清楚的历史阶段边界。
3. 删除它后，世界的因果逻辑、组织关系、能力边界或稳定视觉形态是否会变得无法解释。
4. 它是否属于世界规则，而不是某个资产的局部外观或某次行动。

只有第 1、2 项成立，且第 3 项至少命中一类具体影响时，才进入 `scriptAnalysis`。无法唯一判断的冲突写入待确认；证据不足但值得说明的候选写入 `exclusions`，不得补造。

### 2. 收录与排除

优先收录以下有解释力的事实，但不要把这些类型当成固定栏目：

- 时空、地理、生态或灾变如何限制生存和空间形态。
- 能力、技术、资源或制度如何获得、使用、流通，以及其门槛、代价和失效条件。
- 组织、阶层、物种或地域之间稳定的权力、依赖、禁令和利益关系。
- 历史事件已经造成、并在当前阶段持续生效的结构性结果。
- 能持续约束建筑、服饰、装备、交通、材料或群体生活方式的共同条件。

排除以下内容：

- “赛博朋克世界”“强者为尊”“科技发达”等没有具体机制的题材标签。
- 谁去了哪里、打败了谁、拿到多少资源等剧情流水和一次性策略。
- 情绪、悬念、主题评价，以及“体现了……”“展现了……”之类分析结论。
- 只属于一个角色、场景或道具的局部外观；它们进入对应资产记录。
- 现实常识、类型片常识，或原文没有确认的合理猜测。

### 3. `item` 命名

`item` 固定写成 `具体锚点｜规则维度`，并且只使用一个全角分隔符 `｜`。

- 左侧写剧本中的专名、明确群体、具体制度、资源、技术、生态或空间系统。
- 右侧写本条事实真正描述的关系或机制，如“准入与代价”“供给边界”“统治合法性”“阶段性失效”。
- 一个 `item` 只代表一个可稳定更新的语义命题，不得用“世界背景｜基本设定”“势力｜关系”“科技｜水平”等空泛标签充当容器。
- 同一主体的不同规则维度分别建项；同一规则发生历史变化时，在一条完整事实中写清阶段边界。只有两个阶段会持续产生不同制作约束时，才拆成两个带阶段限定的 `item`。

### 4. `content` 写法

`content` 使用自然中文写一个完整、可独立理解的事实。按原文实际具备的信息组织，不强行补齐缺项：

1. 先说明主体、规则或稳定关系是什么。
2. 再说明适用条件、范围、门槛、代价、例外或失效边界。
3. 最后说明它造成的结构性后果，包括权力、资源、生活方式、空间形态或稳定视觉结果。

不要写字段标签，不要写证据位置，不要提“本集”“剧本”“资产设计”或分析过程。专名第一次出现时交代其在当前命题中的身份，避免只写“他们”“该力量”“这一制度”等失去上下文的代词。

### 5. 跨集合并

- 先比较语义命题，再比较字面名称。不同名称描述同一事实时，统一到首次建立的规范 `item`。
- 后文只是补充同一命题时，提交包含旧事实与新信息的完整整合版 `content`；同步会全量替换旧值，禁止只提交新增一句而抹掉旧设定。
- 后文改变原规则时，在完整 `content` 中同时保留旧阶段、触发变化的条件和新阶段；不得把历史状态改写成仿佛一直如此。
- 后文与旧记录冲突且无法唯一解释时，保留旧事实并写待确认，禁止静默覆盖。
- 只有主体或规则维度确实不同才新增 `item`；不要为同义改写建立重复条目。

## 全剧综合

### 分页草稿

每读一页事实，把新事实并入已有因果簇，而不是把 40 条逐项缩写后串接：

1. 识别这一页新增的根前提、运行机制、组织关系、生活后果和阶段变化。
2. 将同一因果链的事实合并，保留专名、条件、代价、例外和时间边界。
3. 删除同义重复，发现冲突则停止综合并回查事实库，不在总览里自行调和。
4. 保持草稿紧凑，但不得把有辨识度的机制压缩成“科技发达”“局势复杂”等类型套话。

### 最终正文

按当前剧本真正存在的依赖关系组织段落。通常先交代使世界区别于同类型作品的根前提，再解释关键机制如何塑造权力与资源，继而落到群体生活、空间和物质文化，最后处理全剧范围内的结构性变化；没有对应内容就跳过，不预设栏目。

每段只承担一个因果簇，段内使用“前提 → 机制与边界 → 后果”的推进。总览必须像世界说明书，不像剧情简介、设定清单或观后感；正文不得出现集数、分析过程、Cache、资产表或制作建议。不要以“这是一个……的世界”“本剧讲述……”“故事围绕……”开头，首句直接给出本剧最具区分度的事实。

## 提交前质量门

在 `sync` 或 `finalize` 前逐项自检；任一问题答“否”就先改写：

1. 只看 `item`，能否知道具体主体和规则维度，而非泛化栏目？
2. 只看 `content`，能否说清至少一条具体关系，并保留原文已有的条件、边界或后果？
3. 每个判断能否回到剧本明确事实，而非类型常识或合理脑补？
4. 同名更新是否保留了旧记录中仍然有效的信息与历史边界？
5. 总览是否解释“为何如此、如何运转”，而不是复述“发生了什么”？
6. 删除专名后如果能无损套用到大量同类作品，是否还有机制信息需要补回？
7. 是否清除了空话、同义反复、主题评价、逐集痕迹和内部工作术语？

## 形式示例

差：

```json
{"item":"世界背景","content":"这是一个科技与魔法并存、各方势力争夺资源的世界。"}
```

好：

```json
{"item":"晶髓能源｜开采垄断与使用代价","content":"晶髓是浮空城市唯一稳定能源，只有议会许可的矿团能够合法开采；未经净化的晶髓会侵蚀操作者神经，因此民用设备采用封闭管线，黑市器械则普遍保留粗糙的隔离结构。"}
```

示例只展示信息结构，不得把其中名词或设定迁移到实际项目。

# Asset type 选择规则

## 使用已经确定的制作路线

单集分析已经按 [asset-rules.md](asset-rules.md) 确定 Excel Sheet。出图阶段直接把 Sheet 当作内部制作路线，再据此填写专业的 `Asset type`；不得因为姓名、台词、物种称谓或剧情身份重新跨 Sheet 分类。内部类别只用于联动 `Primary request`、`Scene/backdrop` 和 `Composition/framing`，不得直接把“角色、生物、群演、场景、道具”这些中文名称塞进 `Asset type`。

| Excel 资产类别与主要主体 | 内部资产类别 | `Asset type` 输出 |
|---|---|---|
| 角色 Sheet 的人形单体 | 角色 | `character concept design` |
| 生物 Sheet 的非人解剖单体或物种标准 | 生物 | `creature-concept` |
| 群演 Sheet 的跨物种群体候选 | 群演 | `background character concept design` |
| 场景 Sheet | 场景 | 按场景子类型表选择 |
| 道具 Sheet | 道具 | 按道具子类型表选择 |

## 角色、生物与群演边界

三类 Sheet 都可以承载有剧情身份的主体，但制作目标不同：角色解决人形单体的脸部、体态与完整穿搭；生物解决非人解剖单体或物种标准；群演解决人类、异族、兽群或机械群体的共同规律和必要候选差异。出图阶段不得互相覆盖路由。

生物固定放在角色后的独立 Excel Sheet，并执行：

- `Asset type` 使用 `creature-concept`。
- `Primary request` 的末尾内部资产类别使用“生物”。
- `Scene/backdrop` 使用“纯白背景”。
- `Composition/framing` 固定使用单行五列的五候选设定板，为同一生物资产生成五个不同的可选外观变体，供用户选型；五个候选必须遵守制作说明中的共同硬设定，但应具有清晰的设计差异。

群演固定使用 `background character concept design`、纯白背景和五候选构图，制作说明必须明确实际群体的人形、非人解剖或机械共同规律。背景动物、角色宠物、携带物、服装纹样、徽章图案或场景中的生物陈设，只有需要单独制作稳定参考图时才另建资产；否则保留为所属资产的从属元素。

## 场景子类型

| `Asset type` | 判断标准 | 示例 |
|---|---|---|
| `environment concept art` | 综合室外环境，或制作说明不足以判断更具体类型时的默认值 | 古镇街道、山谷、港口、废墟群 |
| `interior set concept art` | 主体是可调度的室内空间 | 酒馆内部、办公室、飞船驾驶舱 |
| `environment landmark design` | 主体是地点中的标志性视觉锚点 | 城市巨塔、祭坛、山门、纪念建筑 |
| `architecture concept design` | 主要任务是设计建筑本体，而不是周边环境 | 宫殿、教堂、堡垒建筑方案 |
| `modular environment kit concept` | 交付目标是可重复拼装的场景模块 | 城墙直段、转角、门楼、屋顶套件 |
| `foliage / natural asset concept design` | 主体是植被、岩石或自然资产体系 | 异世界巨树、沼泽植物、岩层套件 |

## 道具子类型

| `Asset type` | 判断标准 |
|---|---|
| `vehicle-concept` | 车辆、飞行器、船舶、机甲和其他交通工具设计 |
| `prop-object-concept` | 道具、武器、工具、设备、家具或具有叙事作用的物件设计；无法判断更具体类型时的默认值 |
| `costume-concept` | 服装、盔甲、制服和可穿戴装备设计 |

每项任务只能输出一个最贴切的专业值。场景或道具子类型必须由主要交付目标决定；从属元素、背景陈设、携带物、镜头景别和构图比例不得改变主要 `Asset type`。最终发给 `image_gen` 的字段中只能保留选定值，不能保留候选列表或 Agent 判断说明。

## 联动字段固定模板

角色、场景与道具的 `Primary request` 使用：

```text
为<制作类型>生成<Excel“制作说明”原文>所描述的<内部资产类别>。
```

制作类型固定为：二次元=`日系二次元动画`，CG=`AAA级游戏制作`，真人=`真人电影`。制作说明必须使用当前资产的完整原文，不概括、不改写。

生物使用“为同一生物资产生成五个不同可选外观变体”的专用请求，并把完整制作说明作为五个候选共同遵守的硬设定；群演使用“生成制作说明所描述的可互换群体视觉体系”。生物五候选用于五选一，群演五成员用于同一体系内共存，二者不得互换语义。

`Scene/backdrop` 使用：

- 角色、群演、生物、道具：`纯白背景`
- 场景：根据制作说明填写具体地点、环境、时代、时间和天气。

`Composition/framing` 使用：

- 角色：`16:9横向角色三视图设定图。展示同一角色的正面全身、严格侧面全身和背面全身，并附带角色正面脸部特写。所有全身视图等高、比例一致、脚底对齐、完整可见，彼此不得遮挡。`
- 生物：`16:9横向生物五候选设定板。固定展示同一生物资产的五个不同完整外观变体，采用单行五列横向排列；全部遵守制作说明中的共同硬设定，同时形成清晰且合理的设计差异，供用户选型。`
- 群演：`16:9横向群体候选设定板。单行五列展示五个可互换成员变体；共同轮廓、物种或材料规律、制服或结构语言统一，每个成员使用符合其身体结构的中性全身姿态。`
- 场景：`根据 Excel“制作说明”中的场景类型、空间结构、环境叙事目标、时间和天气，自动填写与该场景匹配的镜头景别、视线高度、透视关系、空间层次和视觉中心。`
- 道具：`单件道具完整展示，主体居中，轮廓清晰，不得裁切，四周保留充足且均匀的留白。`

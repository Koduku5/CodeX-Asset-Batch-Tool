# 制作说明、剧本设定与推演依据协议

## 字段职责

`制作说明` 只承担当前资产的专属视觉定义，使用自然、连续的中文描述，不写视图编排、生成方式或后端提示词标签。内置 `image_gen` 会在出图阶段把制作说明装填进结构化 Prompt；API 使用自己的提示词组装路径。

`剧本设定` 只记录剧本明确给出的事实。信息不完整时，在末尾统一添加“其余信息剧本未标明”，不要输出逐项缺口清单。

`推演依据` 只解释补全方案如何受到世界观、环境、功能、身份层级和资源条件约束，不复述剧本硬设定或最终制作说明。没有发生推演时写“无需推演，制作说明均来自剧本明确设定”。

角色、生物与群演的关系和归属写入 `阵营`；剧情身份与硬事实写入 `剧本设定`。这些字段已经承载的信息，不在制作说明中重复。

资产类别完整服从 [asset-rules.md](asset-rules.md) 的视觉制作路线。剧情中的“角色身份”不能改变制作说明的类别核心：需要专属稳定视觉身份的人形配角仍写人形角色；不需要固定面孔的普通单人 NPC 写群演；生物主角仍写非人解剖，非人群体仍写群体共同规律与必要差异，具有人格的坦克型机器仍写机械结构。

## 信息选择原则

制作说明必须先达到当前类别可直接出图的核心完整度，再筛选附加细节。标准不是字数越少越好，而是让生成模型得到一套明确、完整、可稳定复现的资产预设，同时不把与当前资产无关的信息变成多余约束。

逐项判断候选信息，只在满足下列任一条件时写入制作说明：

1. 剧本明确给出，并且会改变资产的可见结果。
2. 虽未直接给出，但缺少它就无法形成可制作、可复现的完整方案；补全结果能够由世界观事实、使用环境或功能需求约束。
3. 它是区分当前资产与同类资产、维持跨镜头一致性所必需的稳定识别信息。

分类核心预设规定的是必须达到的成像完整度，不是要求逐项输出固定标签或罗列所有可能属性。这条只约束 Excel `制作说明`的写法，不改变内置 `image_gen` 路由中 `promptFields` 的固定字段名与顺序。核心设定缺失时，应依据剧本和世界观完成一套明确方案；核心设定已经完整后，再加入的细节必须确实有助于辨识、复现或功能表达。缺失项、设计过程、采用理由和路由已经提供的生成要求不进入制作说明。

`制作说明` 交付的是已经收敛的共同硬设定，不在分析阶段替出图模型预写候选方案。生物出图会在这套共同设定内发散五个不同的可选外观变体，供用户选型；群演出图会生成五个符合该普通 NPC 功能或群体体系的可替换外观，单人 NPC 可任选其一，群体资产可让成员共同存在。候选差异都不是剧本硬事实，不写入 `剧本设定` 或 `推演依据`。

## 设计流程

1. 提取当前资产在剧本中的明确事实，写入 `剧本设定`。
2. 按下方分类核心预设检查现有信息是否已经达到可直接出图的完整度。
3. 对核心预设中的缺口查询相关世界观原子事实，补全到可以形成明确方案为止。
4. 对核心预设以外的候选细节按“是否有依据、是否可见、是否有助于复现”筛选一次。
5. 把通过筛选的最终视觉结果组织成自然描述，写入 `制作说明`。
6. 把实际发生的补全逻辑写入 `推演依据`。

## 分类核心预设

以下内容定义每类资产应当达到的最低成像完整度。它们需要落实成明确方案，但不要求使用固定字段顺序，也不要求穷举每个子项。

### 角色

必须形成完整、详细的人形单体外表设定：明确整体年龄感或人形阶段、身体比例与体态轮廓、脸部明确识别锚点、发型或头部外观，以及从头到脚的完整着装。没有剧本依据时不主动固化普通面部细节，由首次出图发散确定。服装款式、搭配层次、配色和主要材质写到能够形成确定造型；属于该造型的固定装备按实际情况写入。人形外星种族、拟人主体和人形机器人仍按可见的人形结构与穿搭描述，不用物种或机械身份代替外观。

### 生物

必须形成完整、详细且可独立复现的非人解剖单体或物种标准：明确生物类型、整体尺度与体态轮廓、头部与感官器官、躯干和肢体结构、运动方式、皮毛/鳞片/甲壳等表面材质、稳定配色与关键识别特征。剧本明确存在角、翼、尾、触须、外骨骼、装备或其他特殊结构时，写清数量、位置、连接关系和可见形态；没有依据时不得新增能力效果或独特器官。有名字、台词或独立剧情身份不改变生物制作核心；若交付目标是可互换群体而非单体解剖，则改按群演规则制作。制作说明只锁定五个候选必须共同遵守的硬约束，不预先写出五套设计。

### 群演

普通单人 NPC 必须形成符合岗位、功能和场合的完整外观范围，包括体态、从头到脚的着装、主要材质配色与必要装备，但不得把普通面孔固化成专属身份。群体资产必须形成完整、详细的共同视觉体系：人类与人形群体明确共同体态范围、完整着装或制服体系及必要成员差异；兽群、异族群体明确共同物种轮廓、表面规律和可持续复用的差异范围；机械群体明确共同结构语言、功能分型与稳定识别系统。两者仍使用同一个群演类别，不增加子类型，也不在制作说明中预写五套候选。具体首领或需要固定身份连续性的成员按主要制作任务另建角色、生物或道具资产。

### 场景

必须形成可直接用于生成场景关键帧的完整视觉预设：明确场景的空间性质与尺度、核心视觉主体、画面中的空间层次和位置关系、需要持续保留的固定结构或陈设，以及统一的材质配色、基础光照和环境氛围。描述应让画面能够具体落地；与该地点的构图、辨识和调度无关的建筑细目不必增加。

### 道具

必须形成完整、详细的独立物件设定：明确整体尺度与轮廓、决定辨识和功能的关键结构、主要材质与配色；只有当开合、连接、握持或变形方式会影响实际使用和外观时，才进一步明确对应结构。载具、机甲与机械主体补充主要结构分区、驾驶或承载方式、关节和运动机构、舱门与开合关系；存在变形时写清变形前后的主要构型与可见连接逻辑。独立服装补充完整廓形、穿着层次、闭合结构和主要面料。剧情人格不替代可见机械或物件描述。

## 阵营格式

角色、生物与群演使用两级归属：`国家或组织｜具体归属（身份）`。例如 `组织A｜部门B（负责人）`、`本地居民｜家庭成员（父亲）`、`生物族群｜物种群（首领）`。剧本明确没有组织时写 `无明确阵营｜独立个体（身份）`；身份尚未揭示时写 `剧本未明｜待确认个体（身份未明）`，不得为填字段而编造组织。

## 导出前自检

- 制作说明脱离剧本上下文后，是否仍能作为目标资产的完整主体视觉定义。
- 角色是否具备完整人形外表与着装，生物是否具备完整非人解剖与表面特征，群演是否按实际物种或材料具备共同规律与必要差异，场景是否具体到可以生成关键帧，道具是否具备明确的物件、服装、载具或机械结构。
- 每项信息是否有依据、能被画面表现，并对辨识或出图有实际作用。
- 是否既满足分类核心预设，又没有为了补齐所有可能属性而加入额外约束。
- 删除推演依据后，制作说明是否仍是一套完整、确定的最终方案。
- 剧本设定是否只保留硬事实，推演依据是否只解释实际发生的补全。
